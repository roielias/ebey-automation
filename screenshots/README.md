## Full Test Execution Screenshots

During actual test runs, all screenshots are automatically saved here with timestamps.

**Note:** Most screenshots are not committed to Git to keep repository size manageable. 
Full test run screenshots can be generated by running:

```bash
pytest tests/ -v
```

All failure screenshots will be automatically saved with descriptive names.
